- Margin of victory (votes & %)

### 📍 Locality-Based Insights
- Area-wise voting patterns  
- Stronghold vs weak zones  
- Locality dominance classification  

### 📈 Party Performance
- Booth-wise win distribution

## 📦 Data Description

### 📄 Raw Dataset
- `madurai_west_results.xlsx`

- Structured for detailed filtering and analysis

- `Locality_Dominance.csv` → Area-wise dominant party
