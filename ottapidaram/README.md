# 🗳️ Ottapidaram Election Result Analysis

This folder contains detailed **booth-wise election analysis** for the **Ottapidaram constituency**.

---

## 📊 Overview

The analysis provides insights into:

- Booth-level vote distribution  
- Party-wise performance comparison  
- Identification of strong and weak booths  
- Detection of critical swing booths

## 📦 Data Description

### 📄 Excel File
- Contains complete polling station results  
- Includes vote counts for all major parties  
- Can be used for filtering, sorting, and deeper analysis  

### 📈 Charts
- Booth-wise visual representation of results  
- Helps in quick comparison between parties  
- Useful for identifying trends and patterns  

---

## 📌 Key Insights Covered

- ✅ Booth-wise winner identification  
- ✅ Vote percentage calculation  
- ✅ Party ranking (1st, 2nd, 3rd) per booth  
- ✅ Stronghold vs weak booth analysis  
- ✅ Critical swing booth detection

## 🚀 How to Use

1. Open the Excel file in `data/`  
2. Review booth-level results  
3. Refer to charts in `charts/` for visual insights  
4. Identify:
   - High-performing booths  
   - Low-performing booths  
   - Competitive areas
