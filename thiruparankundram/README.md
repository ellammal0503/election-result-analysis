## 📊 Key Analysis Performed

### 🗳️ Booth-Level Results
- Winner and runner-up identification  
- Margin of victory (votes & %)  

### 📉 Swing Booth Detection
- Identifies booths with low margin (<5%)  
- Highlights high-impact competitive areas  

### 📍 Locality-Based Insights
- Area-wise voting patterns  
- Stronghold vs weak zones  

### 📈 Party Performance
- Booth-wise win distribution  
- Comparative analysis across parties  

---

## 🔥 Key Insights

- Identification of **critical swing booths**  
- Detection of **closely contested polling stations**  
- Clear visibility of **party dominance across regions**

## 📦 Data Description

### 📄 Excel Dataset
- Contains raw polling station data  
- Includes vote count for each party  
- Structured for filtering, sorting, and analysis  

### 📈 Charts
- Booth-wise visual representation  
- Easy comparison across parties  
- Enables quick interpretation of trends  

---

## 🚀 Usage

1. Open the Excel file in the `data/` folder  
2. Explore booth-level vote distribution  
3. View charts inside `charts/polling_station_charts/`  
4. Identify swing booths and strongholds
