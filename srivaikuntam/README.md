# 🗳️ Srivaikuntam Election Result Analysis

This folder contains detailed **booth-wise election analysis** for the **Srivaikuntam constituency**.

---

## 📊 Overview

The analysis focuses on:

- Vote share distribution across polling stations  
- Party-wise competition analysis  
- Locality dominance patterns  
- Identification of closely contested booths
